# Kret Check

เว็บบล็อกท่องเที่ยว **เกาะเกร็ด ชุมชนมอญ นนทบุรี**
งานส่วนที่ 2 — ออกแบบโครงสร้างหน้าเว็บ โลโก้ และโทนสีให้ตรงกับ Persona ที่วิเคราะห์ไว้ในงานส่วนที่ 1

> `Kret` = เกาะเกร็ด · `Check` = เช็กอิน และ เช็กข้อมูลก่อนไป

**Persona:** Gen Z อายุ 18–26 ปี — เขียนแบบ mobile first แล้วขยายขึ้นไปหาจอใหญ่

---

## เปิดดูยังไง

เว็บนี้เป็น static HTML ล้วน ไม่ต้อง build ไม่มี dependency

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย หรือถ้าอยากให้ path ทำงานเหมือนตอน deploy จริง
ให้เปิดเป็น local server:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

## กฎที่ต้องรักษาก่อนแก้อะไรก็ตาม

อ่านฉบับเต็มใน [HANDOFF.md](HANDOFF.md) — สรุปสั้น ๆ ตรงนี้

1. **สีทุกสีมาจาก `assets/css/tokens.css` ที่เดียว** ห้ามเขียน hex ลงใน `main.css` หรือใน HTML
2. **ใช้ได้แค่ห้าสี** ถ้าต้องการเฉดใหม่ ให้ไล่เข้ม/อ่อนจากห้าสีเดิม
3. **ทุกคู่ตัวหนังสือ/พื้นหลังต้องได้อย่างน้อย 4.5:1** (WCAG AA) เช็กก่อน commit
4. **navbar · hero · สิ่งอำนวยความสะดวก · footer ล็อกสีไว้ตายตัว** ไม่เปลี่ยนตามโหมดกลางวัน/กลางคืน
5. **ต้องมี `background` ที่ทั้ง `html` และ `body`** ไม่งั้นโหมดมืดพัง
6. **ห้ามใช้ `-webkit-text-stroke` กับพาดหัว**
7. **mobile first** ขยายด้วย `min-width` เท่านั้น ห้ามใช้ `max-width`
8. **กล่องสรุปในหน้าบทความต้องอยู่บนสุดก่อนเนื้อหา**
